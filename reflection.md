# Reflection

The biggest change between Stage 1 and Stage 2 was the focus of the project. During Stage 1, I used Claude's Cowork feature to consolidate information from multiple fictional onboarding files into one organized dataset. The emphasis was on gathering information, identifying missing documentation, and organizing it into a format that managers could use. During Stage 2, the focus shifted to building an interactive dashboard that allowed managers to view and interact with the consolidated data through filters, search features, progress bars, and employee detail views.

One moment where I had to correct the agent occurred after the dashboard was first generated. The interface loaded successfully, but no employees were displayed. Instead of starting over, I asked Claude to debug the project and verify that the consolidated dataset was loading correctly. Claude corrected the data-loading issue, and the employee records displayed as expected. This reinforced the importance of testing AI-generated work rather than assuming it is correct on the first attempt.

I would trust this dashboard to organize onboarding information, calculate completion percentages, and help managers quickly identify employees who may need follow-up. These are repetitive administrative tasks that benefit from automation. However, I would not trust the tool to make decisions about whether an employee should successfully complete orientation or whether disciplinary action is appropriate. Those decisions require human judgment, direct observation, and conversations with preceptors. In a real business setting, I would use this dashboard as a decision-support tool rather than as the final authority.
